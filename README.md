# VELANTIS DIGITAL SOLUTIONS — Website

React + Vite multi-page website recreated from the supplied VELANTIS reference screenshots.

## Pages
- `/` — Home
- `/work` — Featured Work
- `/services` — Services
- `/process` — Process
- `/about` — About
- `/booking` — Book a Project (4-step UI)
- `/contact` — Contact

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production
```bash
npm run build
npm run preview
```

## Notes
- The supplied VELANTIS logo is included as `src/assets/logo.png`.
- Reference screenshot crops are used only for the visual mockups/work thumbnails; the page layout, cards, typography, navigation and forms are implemented as real React/CSS UI.
- Replace the mockup images in `src/assets/` with your final project images whenever you have them.
- Update contact details and social URLs in `src/main.jsx` before publishing.
